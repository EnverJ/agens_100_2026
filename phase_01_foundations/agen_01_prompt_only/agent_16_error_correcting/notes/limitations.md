Agent 16 — Limitations

This agent does NOT:
• Apply, automate, or execute any of its own suggestions
• Understand the semantic meaning of errors — suggestions are template lookups, not reasoned advice
• Handle error codes that are not in the template registry — unknown violations produce a generic fallback suggestion only
• Prioritize suggestions intelligently — ordering is by point deduction from the rubric, not by actual impact
• Learn from whether past suggestions were helpful or not

We change one variable at a time.
