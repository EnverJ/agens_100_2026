Agent 18 — Limitations

This agent does NOT:
• Execute or run any of the generated test cases
• Verify that generated steps are accurate for the actual product — hallucinated steps are possible
• Remember or reuse previously generated test cases across invocations
• Validate the requirement input for clarity or completeness — vague requirements produce vague test cases
• Guarantee coverage completeness — the LLM may miss certain edge cases, especially domain-specific ones

We change one variable at a time.
