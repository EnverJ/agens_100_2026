# Concept: Working Memory

Agent 25 takes its name and concept from cognitive science. In human cognition, working memory is the mental workspace that holds information actively in mind during a task — the numbers you keep track of while doing mental arithmetic, the partial sentence you hold while choosing the next word. It is distinct from long-term memory (what you know from the past) and from sensory memory (what you just perceived). It is small, fast, and temporary by design. Agent 25 brings this concept into the agent architecture as a first-class software component.

The need for working memory arises from a specific failure mode in multi-step reasoning chains: intermediate results get lost. An agent that runs a hypothesis step, then an evidence-gathering step, then a conclusion step needs to carry the output of step one into step two and the outputs of both into step three. Without an explicit scratchpad, the only option is to include all previous outputs in the prompt for each step — which rapidly inflates the prompt, wastes tokens, and blurs the separation of concerns between reasoning steps. Working memory solves this by giving each step a named slot to write to and read from, keeping the prompt for each step focused on the current task only.

The key distinction between Agent 25 and the other memory agents in this series is scope. Session memory (Agent 21) is scoped to a conversation — it lasts as long as the user is talking to the agent. Long-term memory (Agent 22) is scoped to all time — it persists across restarts and accumulates indefinitely. Working memory is scoped to a single reasoning cycle — it exists only for the duration of one structured reasoning task, and it is explicitly cleared when that task ends. This tight scope is not a limitation; it is the design. A scratchpad that never clears would accumulate stale intermediate values and cause cross-contamination between reasoning cycles, which is exactly the failure mode working memory is designed to prevent.

The connection to what comes next in Phase 2 is significant. Agents 28 (Chain of Thought), 29 (Deductive Reasoning), 32 (Planning), and 34 (Bug Hypothesis Generator) all require a place to park intermediate reasoning outputs between steps. Agent 25 is that place. It does not reason — it holds. The separation of "a place to hold things" from "a thing that reasons" is one of the clearest examples of the single-responsibility principle applied to agent architecture. Understanding working memory now makes the design of every multi-step reasoning agent in the remainder of Phase 2 immediately legible.
