# Concept — Agent 44: Consensus

A single LLM agent call is an unreliable oracle. For any given question, the model has a non-zero probability of producing the wrong answer — due to training limitations, ambiguous wording in the prompt, context window effects, or random sampling variation at the token level. On factual questions, the error rate might be 5%. On nuanced judgment questions, it might be 30%. In high-stakes decision pipelines, even a 5% error rate across many decisions compounds into a meaningful failure rate at the system level. The question is: how do you reduce per-decision error rates without fundamentally changing the model or the task?

The ensemble principle from machine learning provides the answer. An ensemble combines multiple independent predictors so that individual errors tend to cancel out. If classifier A and classifier B each have a 20% error rate but make errors on different inputs, combining their predictions via majority vote produces a combined error rate dramatically lower than 20%. The key condition is independence: the predictors must fail on different inputs, not the same ones. In LLM agents, this independence is achieved by using separate API calls with no shared context — each call is an independent sample from the model's response distribution. With temperature > 0, each call may also produce slightly different reasoning paths to the answer, further increasing independence.

Majority voting is the simplest aggregation mechanism for discrete answers. Each agent call produces one answer (yes/no, category A/B/C, value X). After N calls, you count how many times each distinct answer appeared. The answer with the most votes wins. With three agents (the default), you need at least two to agree — a majority of two out of three. The probability of a wrong answer requires at least two of the three agents to independently produce the same wrong answer, which requires errors to co-occur. For independent agents with error rate p, the probability of majority error is: 3p² - 2p³. At p=0.20, this is 0.104 — roughly half the single-agent error rate. At p=0.10, this falls to 0.028 — nearly four times better. The math strongly favors ensembling for decisions where accuracy matters.

Agent 44 (consensus by agreement) and Agent 45 (consensus by debate) represent two different approaches to improving decision reliability. In Agent 44, agents do not interact — each answers independently and a vote determines the winner. In Agent 45, agents actively argue opposing positions and a judge evaluates the arguments. Consensus by agreement is faster (N parallel calls + one aggregation) but cannot surface reasoning; it can only say which answer more agents chose. Consensus by debate is slower (sequential calls, more tokens) but produces explicit reasoning on both sides, making the decision process auditable. The choice between them depends on whether you need the answer quickly or need to understand why the answer is what it is.
